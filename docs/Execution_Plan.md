## 2. 工具设计（要点）

- **输入**：客户信息、场景（6 选 1）、对话历史、产品信息（场景需要时）。网页支持自由填写，也能从预置用例一键带入。
- **知识层**：`brand_bible`（品牌语气、可说 / 不可说、价格政策：不打折，可提供刻字、小样、私享闻香会等非价格权益）、`products`（约 15 个 SKU：香水、蜡烛、扩香、室内喷雾、礼盒、续香 / 刻字服务）、`clients`（10–12 位虚构客户）。
- **生成**：系统提示 = 品牌手册 + 场景策略卡 + 用例输入。DeepSeek 以 JSON 输出三条候选，三条的策略刻意不同（如：简短克制 / 温暖关系型 / 带明确下一步）。
- **校验**：规则检查（禁用词、承诺折扣、编造目录外产品、长度、感叹号与表情数量、三条之间的相似度），不通过时自动重试一次，并在卡片上标出问题。
- **网页**：三张卡片、一键复制、显示策略标签和检查结果。

## 3. 测试集设计（50 条）

- 六个场景各 8 条 = 48 条，外加 2 条跨场景边界用例。
- 每个场景的 8 条 = 6 条常规 + 2 条边界。
- 边界用例示例：
  - 生日撞上客户近期有投诉；
  - 对话历史里提到家人过世（不应写喜庆祝福）；
  - 客户拿代购 / 免税价比价；
  - 客户直接要折扣；
  - 买香给伴侣作礼物（隐私：不能对外提及）；
  - 购后反馈皮肤过敏；
  - 沉默 18 个月的客户；
  - 新客户信息极少；
  - 产品推荐场景缺少产品信息。

## 4. 评估方法

1. **规则检查**：在全部 150 条话术上统计通过率。
2. **Claude judge**：五个维度各 1–5 分（品牌调性、个性化、得体不冒犯、事实一致、可直接发送），另给三条之间的差异度打分。
3. **人工盲评**：你评 18 条（每个场景 3 条），不看 judge 分数，评完计算你和 judge 的一致率。
4. **基线对比（时间不够时第一个砍掉）**：裸提示词（不带品牌手册和策略卡）跑同样 50 条，看品牌手册和策略卡带来多少提升。
5. **Good / Not acceptable**：
   - Not acceptable：承诺折扣、事实错误、编造产品、冒犯或越界、不合时宜，任何一条都一票否决。
   - Good：规则检查全部通过，judge 各维度 ≥ 4，且三条有明显差异。
