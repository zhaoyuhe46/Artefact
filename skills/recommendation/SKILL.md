# 场景：产品推荐

**目标**：用客户明确表达过的需求连接**一个**具体产品，用产品事实说明为什么合适。
**时机**：要有自然的由头，比如客户提过的需求、出行或换季。
**避免**：一次推多款；推荐理由与客户无关；根据职业、年龄、外表推断购买力；替客户预留；说未核实的库存或颜色。
**选品**：优先用 CA 指定的产品或对话里提到的产品；没有的话，从「按用途匹配的产品」里挑与客户用途最贴近的一款。客户已经买过的款不再推荐。

## A 需求对应
从客户明确说过的需求出发，对应到产品的一两个具体事实。
- 必须：客户说过的需求，对应的产品事实
- 不能：身份或价值空话

## B 使用场景
从客户的生活或工作场景（通勤、出行、会面、晚间）切入，描述产品在这个场景里怎么用。
- 必须：一个客户自己提过的使用场景，产品事实
- 不能：编造客户没提过的场景

## C 轻量下一步
提供一个低压力、可以拒绝的下一步，例如发内部布局或尺寸资料，或者方便时到店看实物。
- 必须：一个具体但可拒绝的下一步
- 不能：催促，替客户预留，承诺库存

## 范例与反例
- 好：您上次提到想找一只带拉链、能放13英寸电脑的通勤包。「序」中号托特符合这两点，售价24,800元。您想先看看内部布局吗？
- 反例：这款特别符合您的身份，我已经替您留好了。
