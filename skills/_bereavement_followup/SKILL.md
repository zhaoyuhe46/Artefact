# 场景：客户家中有人离世，30 天后的一次问候

**目标**：一次不带任何请求的问候，表达关心。
**避免**：产品、活动、服务、价格；问客户是否有需要；喜庆措辞；追问细节；再次提起离世这件事。

## A 简短问候
一两句简短的问候。
- 必须：问候
- 不能：产品，活动，服务，问句

## B 关心近况
温和地表达关心，希望对方和家人一切都好。
- 必须：关心
- 不能：产品，活动，服务，追问细节

## C 不必回复
问候，并明确告诉对方不必回复。
- 必须：问候，告诉对方不必回复
- 不能：产品，活动，服务
