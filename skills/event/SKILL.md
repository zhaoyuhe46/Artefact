# 场景：活动邀约

**目标**：说明活动的内容、时间和地点，给客户留出选择的空间。
**时机**：活动前一到两周。
**避免**：「VIP」「尊贵」之类抬高客户身份的说法；「必须来」「机会难得」；编造活动细节。
**缺失信息**：资料里写着 TBD 的时间、地点或内容，在正文里原样写成「TBD」，不得编造。

## A 信息清晰
把活动内容、时间、地点说清楚，再加一句为什么想到这位客户。
- 必须：活动内容、时间、地点
- 不能：抬高客户身份，施压

## B 关系版
从客户的兴趣或之前的对话说起，说明为什么想邀请对方。
- 必须：客户真实的兴趣或对话细节，再接上活动
- 不能：编造兴趣

## C 体验描述
描述现场能看到、能了解到什么，让客户自己判断是否感兴趣。
- 必须：活动现场的具体内容
- 不能：资料以外的活动细节

## 范例与反例
- 好：林女士，周六下午店里有一场皮料与养护分享，可以现场了解不同皮面的日常打理。您有兴趣的话，我把具体时段发您。
- 反例：您是我们最尊贵的VIP，必须来，机会非常难得。
